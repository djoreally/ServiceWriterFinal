# ServiceWriterFinal

[![Codeac](https://static.codeac.io/badges/2-1341410779.svg "Codeac")](https://app.codeac.io/github/djoreally/ServiceWriterFinal)

Service Writer is a customer-service operations platform for service businesses, including booking, work orders, quotes, invoices, payments, technician dispatch, messaging, notifications, and PWA workflows.

## Continuous integration

The repository runs automated tests with LCOV coverage on pushes to `main` and `master`. The Codeac coverage upload reads `CODEAC_REPOSITORY_TOKEN` from GitHub Actions Secrets; credentials are intentionally not stored in this repository.
