# Codeac coverage setup

The README includes the Codeac repository badge for `djoreally/ServiceWriterFinal`. Coverage is generated by `.github/workflows/codeac-coverage.yml` on pushes to `main` or `master`, and can also be started manually from GitHub Actions.

Create a GitHub Actions repository secret named `CODEAC_REPOSITORY_TOKEN` and paste the replacement Codeac repository token into that secret. The workflow reads the token only at runtime and does not store it in the repository. If the secret is absent, tests still run and the upload step is skipped.

The workflow runs `npm test -- --coverage`, verifies `coverage/lcov.info` exists, and uploads it to Codeac with the current commit SHA, branch, and JavaScript language identifier. The token that was pasted into the conversation must be revoked and replaced before using this workflow in a trusted CI environment.
